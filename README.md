# ⚽ Mundial 2026

App PWA para seguir el Mundial FIFA 2026. Instalable en Android e iOS.

## Funciones
- 📅 Calendario completo de 104 partidos con sedes y horarios
- 🏆 Fase de grupos con tabla de posiciones en tiempo real
- ⚡ Eliminatorias: Por Ronda y Bracket visual
- 🏆 Polla Mundialista
- 📒 Álbum Panini — marca tus figuras (tengo / me falta / repetida)
- 💾 Datos guardados en el dispositivo (localStorage)
- 📲 Instalable como app (PWA)

## Deploy en Netlify
1. Sube este repo a GitHub
2. En Netlify: **Add new site → Import from Git**
3. Selecciona el repo — Netlify detecta `netlify.toml` automáticamente
4. Click **Deploy site** — listo en ~30 segundos

## Instalar como app
- **Android (Chrome):** Menú → *Agregar a pantalla de inicio*
- **iOS (Safari):** Compartir → *Agregar a pantalla de inicio*
